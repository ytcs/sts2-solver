# Relics

Code: `crates/sts2sim/src/content/relics/*.rs`, one `listener!(ClassName { ... })` per relic (class name = C# class name). Constants are in `content/gen_relics.rs`, generated by `scripts/porting/gen_relics.py` from each relic's `CanonicalVars`; never hand-copy a number (`gen_relics::kunai::CARDS`). Relic-only powers: `content/powers/relic_powers.rs`.

All 300 relic classes are registered, including the Defect orb relics (CrackedCore, InfusedCore, GoldPlatedCables, RunicCapacitor, SymbioticVirus, EmotionChip, Metronome in `defect.rs`; orb hooks in `engine/orbs.rs`).

## Relic state (`Relic { counter: i32, flags: u8, aux: i32 }`)
Every private or saved field of a C# relic maps onto `counter` / `aux` (ints) or a `flags` bit (bools); the mapping is documented above each listener. The `Listener` has three static metadata methods (not hooks, no dispatch):
* `meta_props()`: the relic's `[SavedProperty]` list, e.g. `relic_props![PropDef::int("TurnsSeen", Slot::Counter), PropDef::flag("WasUsed", 0)]`: C# property name, slot, whether the game omits it at the type default (`SaveIfNotTypeDefault`), or a fixed JSON literal (`PropDef::constant`, e.g. FurCoat's empty arrays). The oracle injects scenario `relics[].props` through `SavedProperties.Fill` and dumps `props` through `SavedProperties.From`; `sts2diff` converts both ways with this table.
* `meta_display()`: `ShowCounter ? DisplayAmount : none`; dumped by the oracle as `counter`.
* `meta_initial()`: field initialisers that are not 0 / false (EmberTea `_combatsLeft = 5`, TeaOfDiscourtesy `1`, ...).

`RelicInit { id, counter, flags, aux }` carries a relic's state into `Combat::new`; `Combat::rel(me)` / `rel_mut(me)` access it from a hook (`me.idx` is the relic's index).

## Hooks and engine behaviour
The hook set is canonical (`hooks.rs`; single-variant signatures, one `listener!` per class). Relics use `after_room_entered`, the `*_late` turn-start variants, `should_draw` / `after_preventing_draw`, `modify_x_value` (cards read X through `Combat::x_value`), `modify_card_play_count`, `should_die` / `should_die_late` + `after_preventing_death`, `after_creature_added_to_combat`, `after_modifying_block_amount`, `after_stars_spent/gained`, `try_modify_star_cost`, potion procure / discard hooks, `after_died_to_doom` (`Combat::all_powers_trigger_fatal` answers `ShouldOwnerDeathTriggerFatal`), `after_attack`, `should_take_extra_turn` / `after_taking_extra_turn`, `before_side_turn_end_early`, and the one relic-specific addition `modify_gold_gained` (run-level; `Combat::gain_gold` threads it: Ectoplasm, BowlerHat).

Relic-driven state fields on `Combat`: `gold` (oracle default 99; `sts2diff` injects the scenario's `gold`), `room_type` (0 monster / 1 elite / 2 boss from the encounter id suffix), `deck_upgradable` (FishingRod / WarHammer item counts), `cur_power_card` (`cardSource` of the power application being dispatched), `auto_select`. `spend_resources` is the shared `SpendResources` step of `play_card`. `engine/relic_cmds.rs` (`rel` / `rel_mut`, `has_relic`, `damage_hittable_enemies`, `damage_random_hittable_enemy`, ...) covers what the canonical command set lacks.

### Hooks that need a decision (`shared_choice.rs`)
A hook that needs a decision calls `cx.ask_hand/ask_options(...)`; on `Ask::Pending` it sets `cx.hook_ctx = Some((me, phase))` and `cx.stage = Stage::AwaitChoice`. The turn start (`setup_player_turn` / `turn_cont`) stops after the suspending listener; `resume_after_decision` calls `Listener::resume_hook(me, phase)` (picks are in `cx.choice`) and then `resume_turn_start`. GamblingChip, ToastyMittens, Toolbox and ChoicesParadox work this way. A hook that auto-plays a card (HistoryCourse) calls `cx.auto_play(card, target, AutoPlayType::Default, false)` and relies on the auto-play stack. Whispering Earring pushes the game's `VakuuCardSelector` while it auto-plays: `Combat::auto_select` makes every card-selection screen resolve to the first `max` candidates, so it never suspends. `sts2diff` answers prompts raised during setup (record 0) from the oracle's recorded `choices`.

### Pets, Forge, extra turns (`pets_forge.rs`, `monsters/relic_pets.rs`)
BoneFlute (Osty attacks give block); Byrdpip / PaelsLegion (`Combat::add_pet` creates the 9999-HP do-nothing pet at `BeforeCombatStart`; PaelsLegion identifies its `AffectedCardPlay` by `(card, play_index)` on the play stack); FencingManual (`Combat::forge`); PaelsEye (`should_take_extra_turn`; `before_side_turn_end_early` exhausts the hand; a history query for "a card was played this turn"). DivineRight, RingOfTheSnake, LizardTail, ChemicalX and UnceasingTop live in the shared files and carry the saved-state metadata.

## Validation
Build an A10 Ironclad template (starter relic dropped, a mix of ported cards, Ascender's Bane, the relics under test, their counters in `relics[].props` set next to the thresholds) and run `python3 verify/diff_sweep.py TEMPLATE.json --n 40` (`docs/porting-guide.md`). `python3 tools/fuzz_gen_mix.py --each-relic` (round robin) or `--force-relics A,B` sweeps relics inside random decks (`docs/oracle.md` section 7); `tools/fuzz_gen.py` injects counters from `tools/fuzz_relic_props.json`.

## Known limits
* PaperPhrog / PaperKrane are behaviour of `VulnerablePower` / `WeakPower` (they check for the relic; the relic listeners are empty).
* Monster code that adds status cards through `add_generated_card` counts as "not created by the player" only during the enemy turn (Regalite).
