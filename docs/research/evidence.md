L->W / W->L = near-miss losses won / close wins lost. Model names (h128, r1-r9, td08, gen-2) label experiments; live model `models/current.json`. E6-E10 include multiplayer-only cards (paired comparisons valid, levels not). Tools and eval files named below may since be deleted (git history).
