# Plan
Single plan, current state, forward only. Evidence `docs/research/evidence.md` (E#); game facts `docs/research/game_code.md`. Each stage: goal / status / gate; a stage failing its gate is not adopted. Simulator/search/env changes pass `bash tools/gate.sh` unchanged (a deliberate behaviour change updates its checksum in the same commit).

## 1. Goal and principles
- Goal: win A10 runs with all five characters (Ironclad first); ~90%+ target (user); end HP breaks ties.
- Information contract: only the exact random state is hidden; public and tracked: move patterns + odds, potion-drop chance, rarity offset, unknown-room odds, encounter-bag narrowing, shop prices, removal cost. Hidden until the game reveals it: later acts' maps and act variants (seeded from the run seed); the run model samples them from a library generated with independent seeds, live and offline alike, never from a run's own seed. Forks and replays of a seed are training labels and offline diagnosis only; V's inputs are observable state. Evaluation seeds for any component fitted on logged runs are disjoint from its training seeds: BASE0001-0040 are training-only from E95 on (a model fitted on a seed's logged future carries hidden information about that seed).
- Claims: solver results are lower bounds under the stated solver; < 2 se is a tie; expert choices are evidence, never rules; no blanket bans.
- Validation: harness / instrument changes are judged by paired scripted arms on the same seeds (act reach, deck strength per act, wins); operator rule changes by the ledger (decision agreement and margin, pair deck strength at arrival; `sts2-improve`); the frozen decision gate (`tools/decision_gate.py`) only flags large regressions.
- Venue: the headless server (`OracleCombat serve`) counts (mechanically indistinguishable from the game, E44); Steam copy only for live-parity work; close it when done.
- Operations: RunPod Secure only; $60 remaining and authorized (user, 2026-10-12; $187.48 spent of the first $200); collection cost per 1k fights measured in r10 (search K 32, roots 2048; mixes differ per pod): RTX PRO 4500 $0.72/h 6.1 fights/s $0.033, A40 $0.59/h 4.5/s $0.036, RTX PRO 6000 $2.49/h 12.3/s $0.056 (5090 / 4090 / A5000 were out of stock); shards of >= 12k fights (each process pays ~3 min of startup); wall time over cost; state the hourly price at creation; terminate when done; a pod failing setup twice is replaced; clone the public repo on pods; avoid host 68.164.57.15 (`minRamPerGpu` 90); never `pkill -f pod_job.sh` (PID 1). Every pod job sets `DEADLINE` (epoch s): `scripts/pod_guard.sh` terminates the pod at it or 40 min after DONE / FAILED (budget backstop; pulling and deleting stays the primary path). Local GPU: one heavy job at a time. Scripted arms: n 20 until the first win. Baalorlord main-channel runs are wins (a transcribed death is a misread).

- Harness / operator split (rule: SPEC division of labour; macro has ~200 runs on ~40 seeds, every learned macro value failed held-out seeds, E86, E91-E95):
  - Harness: combat play and P(win) / end-HP given state; deck strength vs a named encounter at a given HP (`eval`, the validated instrument); mechanical DPs where the model is the game (`routes`, `restcalc`, pair potion worth); paired counterfactuals (`--v`); tracked public state (relic counters, bag narrowing, rarity offset, potion-drop chance, prices, slots); enforcement (gate, guards, citations, review lock). Operator play shows components with their validation status, not a verdict; the `decision` line stays for the scripted arm.
  - Operator: the plan (win condition vs the known pair, target deck, build -> complete switch); which counterfactual to ask (speculative picks, removals, composition at the pair); economy the simulator does not price (slots, curses, gold vs relics vs removals), rare events, relic interactions; death attribution and rule edits.
  - Migration (`sts2-improve` I7): a rule the instrument agrees with on >= K = 10 citations becomes a harness default; operator overrides of an instrument that hold are an instrument fix (calibration, horizon), not a rule change.
