# Combat simulator (sts2sim / sts2env / sts2py / sts2diff)
Target: STS2 v0.111.0 (Steam build 24724944), single-player combat, A10 only. Fidelity > throughput > memory. Truth = the game's code, replayed by the oracle. Every simulator/search change passes `bash tools/gate.sh` (search + env checksums, oracle regression traces, RNG goldens, information contract, sync, look-ahead cache exactness); a deliberate behaviour change updates its checksum in the same commit.

## Design
- Crates: `sts2sim` core, `sts2env` batch env + search, `sts2py` bindings (`import sts2`), `sts2diff` differential replayer.
- Truth: decompiled `sts2.dll` in `decomp/` (gitignored; ilspycmd). Port, never guess; class name = id.
- State: plain data, fixed capacities, `Clone` = memcpy, no heap on the hot path. `step(action)` runs to the next decision; every player choice is an `Action`.
- Content: one `listener!` per entity, dense-id dispatch, per-kind hook bitmask. `Dec` mirrors C# `decimal`. RNG: port of `MegaRandom`/`Rng`, golden-tested (`oracle/RngGolden`, `tests/rng_golden.rs`); .NET introsort reshuffle (`sort.rs`).
- Suspension: synchronous recursion mirrors nested awaits. Cards: `on_play(cx, play, phase) -> Flow`, `Flow::Suspend(next)` records a `Decision`. Hooks: `cx.hook_ctx = Some((me, phase))` + `Listener::resume_hook`; turn start `turn_cont`, turn end `end_turn_resume`. Prompts inside draws that cannot pause (Stratagem, `AutoPlayFromDrawPile`) are replayed (`engine/replay.rs`: snapshot, show, restore, re-run with the answer; only when `Combat::strat_possible`). Search determinizes before the action, never at a replayed prompt.
- `Combat` (~19 KB): RNG streams, turn/phase, player, enemies, card arena (`cards[CAP]`, piles = index arrays), relics, potions, orbs, op stack, pending decision, history ring. Rust: `Combat::new`, `try_new`, `new_with` (enchantments, saved props, gold, act), `legal_actions`, `step`, `observe`, `determinize`, `reset_with` / `reset_validated` (bit-identical to `new`). Python: `sts2.VecEnv` (over `BatchEnv`: rayon, 32 MB worker stacks), `sts2.Sim` (one alignable fight), `sts2.provably_unwinnable`.
- Runaway guard (`engine/budget.rs`): per step / look-ahead turn `WORK_LIMIT` 20,000 units (max seen 174), `HOOK_DEPTH_LIMIT` 64, `TURN_LIMIT` 20. Past a limit: `ov::LOOP`, combat over, scored as a LOSS (the game soft-locks: `docs/game-bugs.md` 1).
- Coverage: every non-deprecated card, relic, potion, encounter; powers 256/265, monsters 114/120 (rest multiplayer/test); 23 enchantments, 7 afflictions; 5 characters; acts 1-3 + event encounters.
- Not modelled: run-level deck-copy listeners; `GainsBlock` (approximated by "has a Block var"); non-integer named vars (Tank); "known top card". Unported content is reported (`Combat::missing`, `OUTCOME_UNIMPLEMENTED`), never simulated silently.

## Env contract
Expose exactly what a human can do and see (`crates/sts2sim/tests/observe.rs`, gate).

| action (`ACTION_SPACE` 252, `MAX_CREATURES` 12: read the constants) | legal when |
|---|---|
| `PlayCard{hand_pos, target}` | play phase, `can_play`; one per living enemy for single-target cards |
| `UsePotion{slot, target}` | play phase, `CombatOnly`/`AnyTime` |
| `DiscardPotion{slot}` | play phase, slot filled |
| `EndTurn` | play phase |
| `Pick{idx}` / `Confirm` | a decision is pending |

- Decisions choose `min..=max` of a candidate list: hand selections in hand order; pile selections in a canonical order by visible properties (pile order never leaks); the engine keeps game order (`Decision::cands`, `sts2diff` `step_pick_game_order`). Forced choices auto-resolve. `Pick` toggles; completes at `max` unless `confirm_required`. A skip exists only where the C# allows it.
- Hidden: pile order, RNG states, realized branch outcomes, monster AI state beyond the pattern. Visible: everything else incl. intents, last 4 moves, the move-pattern look-ahead. Tests: `hidden_state_does_not_leak`, `big_pile_order_does_not_leak_in_v2`, pile-selection order.
- Look-ahead (`Combat::lookahead`, `engine/monster.rs`, `look_turn`): per enemy, next `LOOK_H` = 4 turns, P(move node) over `LOOK_NODES` = 16 + expected attack damage, from a projected copy (player passive; rolls branch at the game's odds over the monster and its `LOOK_JOINT` peers; <= 8 paths per turn; no RNG consumed). Cache exactness: `docs/solver.md`.
- Observation (`observe.rs`, sizes constant and asserted): global, player, relics, potions, hand (15 features per card incl. calculated numbers, affliction amount, replay count), piles as sorted multisets, enemies (displayed number per power), pending decision (64 candidates, `dec_source`, `played`), Regent star costs, Osty, orbs, look-ahead, enemy moves. New sections append at the END. Window limits (simulation unaffected): 8 enemies, 16 powers, 64 cards per pile, 64 candidates.
- Outcomes (`sts2env::OUTCOME_*`): 1 WIN (reward `win + hp_bonus * hp / max_hp`), -1 LOSS (incl. `ov::LOOP`), 2 TRUNCATED, 3 UNIMPLEMENTED, 4 OVERFLOW. 2-4 are truncations: bootstrap, never win/loss.
- Capacities: a full `ArrayVec` raises sticky `Combat::overflow` (`ov::CONTAINER, CARDS, CREATURES, HISTORY, COUNTER, SCENARIO, LOOP`); invalid scenarios return `ScenarioError`. Caps: `MAX_CARDS` 160 (never recycled), `MAX_DECK` 80, hand 10, `MAX_POWERS` 16, relics/potions/orbs 24/4/10, hook snapshot 256, `MAX_PICK` 64, `HIST_CAP` 160. Corpus peaks 143 cards, 13 powers, 8 creatures, 39 candidates.
- `BatchEnv` resets in place via `reset_validated` (allocation-free; == `new` bit for bit, also vs the oracle with `STS2DIFF_REUSE=1`).

## Porting
Done = 0 mismatches vs the oracle on scenarios exercising it, at A10 (`ascension: 10`, `max_potion_slots: 2`, Ascender's Bane; `asc::val`). Never A0 only.
- Layout: `crates/sts2sim/src/content/{cards,powers,relics,potions,monsters,encounters,enchantments,afflictions}/*.rs`, auto-registered (`build.rs`). Generated, never edit: `content/gen_*.rs`, `ids.rs`; regenerate after a game update with `scripts/porting/` (`gen_defs.py`, `gen_ids.py`, `gen_relics.py`, `flag_multiplayer_cards.py`).
- `listener!(ClassName { fn hook(...) {...} })`, exact C# class name, one per class repo-wide; `//` comments before the macro. Duplicate check: `grep -rho "^listener!(\w*" crates/sts2sim/src/content | sort | uniq -d` prints nothing.
- Hooks (`hooks.rs`): one trait method per C# override; extra args via `cx.dmg_card` / `cx.dmg_result` / `cx.play_serial`; tiers = separate passes. New hook: trait method + `hookbit::bits!` + dispatch at the game's point; append at list ends.
- Cards: stats from `gen_cards.rs`; suspend after `cx.ask_hand/ask_pile/ask_options`; vars via `cx.card_var`, `card_named_var`. Never hard-code a generated number. Powers: only the C# overrides. Monsters: `pub static <SLUG>_DEF: MonsterDef` (`monsters/nibbit.rs`). Encounters: `spawn_<slug>(rng, ascension)` (`encounters/basic.rs`).
- Hot path: no heap, no `Vec`/`String` in content, `ArrayVec`, no `dyn` beyond the listener table; lists via out-params (`snapshot_into`, `damage_into`); whoever mutates `Creature::powers` calls `sync_secondary(c)`; cost mods via `CostMod::new`.
- Engine helpers (read before writing one): `cx.kill`, `escape`, `heal`, `should_die`; `summon_enemy`, `stun`, `set_move_immediate`; `auto_play` (`RunResult::Suspended` -> `Flow::Suspend`), `transform_cards`, `clone_card`, `x_value`; per-instance defs via `cx.card_def(c)`; per-card state `Card::counter`; `cx.draw_cards(n, false)`. Monster-move decisions: `ask_options`, on `Ask::Pending` set `hook_ctx` + `Stage::AwaitChoice`. History, never private counters (`hist_*`; a new per-turn counter kind joins `HKind::in_ring()`). Stars `energy.rs`, `regent.rs`; Osty `pets.rs`.
- Capacities never fail silently: push everything or `util::raise_overflow`. `reset_validated` destructures every `Combat` field (a new field = compile error).
- Relics: `content/relics/*.rs` grouped by trigger; constants from `gen_relics.rs`; state `Relic { counter, flags, aux }` mapped from every saved C# field; `meta_props()` = `[SavedProperty]` list the oracle and `sts2diff` convert through. Network-visible relics: `relic_mask.rs` (`tools/gen_relic_mask.py` from `data/relic_classes.json`). Paper Phrog / Krane live in `VulnerablePower` / `WeakPower`.
- Colorless/curses/statuses: `content/cards/{colorless_a,colorless_b,curses_pool,status,tokens,curses}.rs`. Calculated damage = `CalcBase + ExtraDamage * mult`. Multiplayer-only cards: single-player behaviour. Known divergence: listeners after a suspending one in the same turn-start pass run before the answer (Entropy + Rolling Boulder can diverge).
- `FromChooseACardScreen(canSkip: false)`: the oracle patches `canSkip` in so `min` = 1 matches.

## Validation loop
1. A10 scenario JSON with the ported entities.
2. `oracle/combat/oracle.sh run S.json --random SEED --out T.jsonl`; `cargo build -p sts2diff && target/debug/sts2diff run S.json T.jsonl` (`dir DIR`). `ok` = every step incl. all 9 RNG streams matched; `STS2DIFF_DUMP=N`, `STS2DIFF_LENIENT=1`; exit 3 = unimplemented.
3. Fix until clean over several seeds; the oracle trace beats your reading of the C#.
4. Non-obvious rule: freeze `oracle/regression/NAME.scenario.json` + `NAME.jsonl` (`cargo test -p sts2diff --test regression`).
5. Fuzz, then the gate. Live: `python -m agent.fidelity_sweep`.

## Oracle (`oracle/combat/`, build: its README)
- The game's own combat code on `ModelDb` / `RunState` / `Player`, no Godot runtime. Stubs: Godot native calls hit a no-op; Harmony patches for OS/time/localization/persistence; `TestMode.TurnOnInternal()`; game `Log.Error` is fatal (whitelist `Boot.cs`); single-threaded FIFO `SynchronizationContext`.
- TestMode differences: Rolling Boulder damages all enemies in one batch; `FromChooseABundleScreen` takes `bundles[0]`. No in-combat RNG draw is TestMode-gated.
- Scenario JSON: `name, ascension, encounter, character, hp, max_hp, max_energy, gold, max_potion_slots, base_orb_slots, seed` (STRING), optional `rng` stream overrides (`shuffle, combat_card_generation, combat_potion_generation, combat_card_selection, combat_energy_costs, combat_targets, monster_ai, niche, combat_orbs`), `total_floor, act, deck` (ordered; `{id, upgrade, enchantment, props}`), `relics` (hook order, props), `potions`, `apply_ascension_effects`, `script` (`play {hand_pos, target}`, `choose [..]`, `end_turn`, `use_potion {slot, target}`), `policy {kind random|playall|stall, seed, endw, atkw, potw, max_steps, max_rounds}`. Omitted inventory = starting inventory. `choose` answers prompts in order as the game hands the list to the selector.
- Injection = the save-load path; deck order feeds the initial `UnstableShuffle`; the seed string matters even with `rng` (encounter Rng = `Seed + TotalFloor + xxhash64(encounter)`); pre-combat draws precede record 0.
- Trace (JSONL, schema `Dump.cs`): record 0 after setup and first turn start, then one per player action: full visible state, prompts, history `log`, all 9 RNG streams.
- Deterministic (same scenario = byte-identical trace); Windows reproduces the Linux traces. Limits: one player, x86-64, build pinned by `sts2.dll`.
- Fuzzing: `tools/fuzz_gen_mix.py` (any character, act-scaled picks, enchantments, relic counters, potions, any encounter; `--focus mix|colorless|junk|gen|turn|cross`, `--mode uniform|greedy|stall|deep`, `--each-potion`, `--each-relic`, `--force-*`). Example `python tools/fuzz_gen_mix.py --n 1500 --seed r3 --out target/fz/r3 --jobs 6`. Do not rebuild the oracle or `sts2diff` mid-round (`STS2DIFF=` copy). Last full round ~250,000 fights, 0 residual mismatches; rerun after any content or engine change.
- Whole run (`run-replay`, `RunReplay.cs`): `NGame.StartNewSingleplayerRun` path (acts from the `act_selection` Rng as `StartRunLobby`, `UnlockState.all`, ascension effects on), TestMode UI factories return null. Headless stand-ins for UI-owned steps: post-combat `CombatRoom.OfferRoomEndRewards` (NCombatUi), rewards via `RewardsSet.testSelector`, card reward via `ICardSelector.GetSelectedCardReward`, treasure `DoNormalRewards`/`DoExtraRewardsIfNeeded` + `RelicsAwarded` -> `RelicCmd.Obtain` (NTreasureRoomRelicCollection), `EnterNextAct`, `EnterMapCoord`. TestMode deviations: `MerchantPotionEntry.CalcCost` skips its `Shops` draw (patched back, `Patches.RealRunRng`); still unpatched: `Cauldron`/`CallingBell` fixed test rewards, `FromChooseABundleScreen` takes `bundles[0]`, tutorial/discovery overrides off (match a fully unlocked profile). Event option labels from `data/events.json`; map picks without a column use `agent/reenact.py`'s later-rooms consistency rule. Baalorlord `hMrQSndDvPc`: 199/199 steps, every combat decision (25 fights), reward set, shop, treasure, act map matches the live replay log (run4), ends 23/77.
